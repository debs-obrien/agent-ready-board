Agent-ready board comparison

Two live Kanban demos from the same prompt: one built with the UI SDK (vercel-labs/ui), and one built without it. Same features on both: three columns, cards, keyboard moves, Assign-to picker, actions menu, and edit dialog.

Try the same moves on both.

  1. Tab to a card’s move handle
  2. Space to pick up
  3. Arrow keys to move
  4. Space to drop
  5. Escape to cancel

Turn on a screen reader (software that speaks or brailles what is on screen, such as VoiceOver on Apple devices or NVDA on Windows) and listen while you move a card. The SDK board announces each step; the plain board does not.

Tested in Chrome on Linux.
